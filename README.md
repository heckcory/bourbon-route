# The Bourbon Route

Kentucky 2027 trip companion, app v3.3. Static HTML/CSS/JavaScript with original Sketchbook artwork.

GitHub Pages serves main branch / (root). All asset and PWA paths are relative for /bourbon-route/. No build or paid backend required. Preview with python -m http.server.

Tour times and prices are proposed, not confirmed reservations. Native sharing opens each visitor own phone share sheet; no Tesla account connection. Photo Hunt data stays on each device with export/import backups. Live navigation/booking sites need internet; use Check offline readiness before travel.

For future releases bump sw.js VERSION and precache.json version together. Never commit credentials or private reservation information to this public repository.

Verification: 19 automated regression tests passed before migration; mobile layout and browser navigation checked. Actual phone-to-Tesla handoff still needs device verification.
